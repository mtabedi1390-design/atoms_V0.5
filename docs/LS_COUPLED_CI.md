# Fixed-Orbital LS-Coupled Multiconfiguration CI (`ATOMS v0.7.1`)

## 1. Explicit Method Definition (`fixed-orbital-ls-ci`)

ATOMS `v0.7.1` solves the nonrelativistic clamped-nucleus electronic Hamiltonian:
$$\hat{H} = \sum_{i=1}^N \left(-\frac{1}{2}\nabla_i^2 - \frac{Z}{r_i}\right) + \sum_{1 \le i < j \le N} \frac{1}{r_{ij}}$$
within a user-configured active space of configurations $\{\mathbf{n}_1, \mathbf{n}_2, \dots\}$ projected strictly onto an orthonormal **Russell–Saunders $(L, S, M_L=L, M_S=S, \Pi)$ CSF basis** $\{|\Phi_\alpha\rangle\}$ built from **fixed** $SO(3)$-symmetric radial orbitals produced by `AtomSphAverageRHF`.

> **Scientific Honesty Boundary:** Self-consistent Multiconfiguration Hartree–Fock (**MCHF**) radial orbital re-optimization is **NOT performed** in `v0.7.1`. All responses carry `method: "fixed-orbital-ls-ci"`, `orbitalOptimizationPerformed: false`, and UI disclosures stating this explicitly.

## 2. Active-Space Modes & Resource Safety Caps

`science/ls_ci_backend.py` exposes four transparent active-space construction modes (`LSActiveSpaceMode`):

1. **`single-config`**: Retains only the reference configuration (captures exact multiplet splitting within one shell, e.g., $2p^2 \to {}^{3}P, {}^{1}D, {}^{1}S$ or $3d^3 \to 2 \times {}^{2}D$).
2. **`valence-cas`**: Keeps core shells (`_canonical_core_nl(Z)` or doubly occupied inner shells) frozen in all determinants and generates all Pauli- and parity-allowed distributions of the valence electrons among the occupied valence $(n, \ell)$ shells (e.g., $\text{Be } 2s^2 \leftrightarrow 2p^2$, $\text{C } 2s^2 2p^2 \leftrightarrow 2s^1 2p^3 \leftrightarrow 2p^4$).
3. **`valence-plus-virtuals`**: Includes occupied valence shells plus all $SO(3)$-symmetric virtual shells $(n, \ell)$ generated by the selected Gaussian basis (`STO-3G` .. `aug-cc-pVTZ`, `def2-SVP/TZVP`), with optional excitation rank truncation (`CIS` = rank 1, `CISD` = rank 2, or full CAS in active shells).
4. **`custom-configs`**: Accepts an explicit semicolon/newline-separated list of $N$-electron configurations sharing the frozen core and filters configurations matching target parity $\Pi$.

### Active-Space Safety Caps
To prevent unbounded exponential explosion or memory exhaustion inside local/container hosts, `science/ls_ci_backend.py` enforces hard pre-allocation limits (`LSCapabilitiesResponse.limits`):
- `maxDeterminants = 12,000` (pre-screening exact count before building matrices)
- `maxCsfs = 2,500`
- `denseDiagonalizationThreshold = 450` CSFs (switches automatically from dense `np.linalg.eigh` to sparse `scipy.sparse.linalg.eigsh` Lanczos/ARPACK above `450` CSFs)
- `maxDenseMemoryMB = 256`

Exceeding these limits raises an explicit, structured `ValueError` (verified on `Fe` large `3s..5p` active space raising `"Active space determinant count exceeds safety limit 12000"`).

## 3. Slater–Condon Hamiltonian & Diagonalization

Given the sparse CSF projection matrix $C \in \mathbb{R}^{N_{\text{det}} \times N_{\text{CSF}}}$ (actually complex-safe real/Hermitian in complex spherical MOs; $H_{\text{det}}$ is constructed via exact vectorized Slater–Condon 0-, 1-, and 2-electron excitation loops in `_slater_condon_sparse_hamiltonian`):
$$H_{\text{CSF}} = C^\dagger H_{\text{det}} C, \qquad H_{\text{CSF}} \mathbf{c}_k = E_k \mathbf{c}_k$$
- **Hermiticity Verification:** $\|H_{\text{CSF}} - H_{\text{CSF}}^\dagger\|_\infty$ is verified `< 3e-15 Ha` across every benchmark.
- **Root Characterization:** For each converged eigenroot $k = 0 \dots n_{\text{roots}}-1$, the engine computes:
  - Total energy $E_k$ ($\text{Ha}$) and excitation energy $\Delta E_k = E_k - E_0$ ($\text{eV}$ and $\text{cm}^{-1}$ via CODATA-2018),
  - Exact $\langle \hat{L}^2 \rangle$, $\langle \hat{S}^2 \rangle$, $\mathrm{Var}(\hat{L}^2)$, $\mathrm{Var}(\hat{S}^2)$, and parity eigenvalue,
  - **Configuration parentage weights** $\sum_{\alpha \in \mathbf{n}} |c_{k,\alpha}|^2$ across contributing configurations (`referenceConfigurationWeight`, `configurationWeights`),
  - Top contributing CSFs (`topCSFs` with configuration label, parentage/seniority label, weight, and signed amplitude).
